- **`/quiz-me`, review an agent-written change by being examined on it.** Reading agent diffs line by line does not scale with the rate agents produce them, and a summary tells you what the author thinks happened. The command resolves the change (a git range, a commit, a PR number, or the working tree by default), reads the diff plus enough surrounding code to know the callers and invariants, draws a compact diagram of what moved, then asks about six questions whose wrong answer would be a merge mistake (why, what happens on a specific failure path, which caller is easy to miss, what a changed test actually proves, what was deliberately left alone) plus one trap about what the diff looks like it does but does not. Answers are graded against quoted diff lines produced by executed commands, never retyped, and the questions you got wrong become the review findings with file:line pointers and a verdict. Read-only and manual-only (`disable-model-invocation: true`). It exists because the habit it replaces ("have the agent quiz you on its own diff") is an on-demand capability you would invoke after most agent PRs, which is exactly the shape a slash command is for, where a CLAUDE.md rule would load on every turn for nothing.
